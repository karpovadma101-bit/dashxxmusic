# «Волна А101» — версия 6 (по мотивам Яндекс Музыки)

Главный приём Яндекс Музыки — «Моя волна», живой пульсирующий шар — переосмыслен как «Волна А101». Светлая тема в дизайн-системе сайта А101: белый фон, фирменный красный #E2232E, графитовый текст, Onest, скругления 20px.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия для хостинга |
| `index-standalone.html` | Один файл 2,8 МБ, работает с диска |
| `audio/`, `font/` | Джинглы AAC + Onest (SIL OFL) |

## Что взято из Яндекс Музыки

Шар-волна: canvas, плывущие ядра света дышат вместе с треком (Web Audio), кольца расходятся в такт; цвет шара меняется по жанру (Pop — красный, Jazz — кобальт XXSOUND, Hip-hop — тёмный) · чипы настроения — как настройки «Моей волны», выбирают жанр · волна не останавливается: после трека сам включается следующий · список треков светлыми строками, у играющего — красный фон-плашка · нижний плеер светлый, прогресс — красная нить по верхней кромке (перемотка кликом по ней).
