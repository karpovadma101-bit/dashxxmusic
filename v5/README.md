# «Город звучит» — версия 5: плейлист (по мотивам Spotify)

Структура Spotify — сайдбар, страница плейлиста с градиентной шапкой, таблица треков, постоянный нижний плеер — перекрашенная в дизайн-систему А101: фирменный красный #E2232E вместо зелёного, шрифт Onest, логотип А101.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия для хостинга |
| `index-standalone.html` | Один файл 2,8 МБ, работает с диска |
| `audio/`, `font/` | Джинглы AAC + Onest (SIL OFL) |

## Что взято из Spotify

Сайдбар с разделами · градиент из цвета обложки в шапке плейлиста · строка «Плейлист · 3 трека, 2 мин 14 сек» · таблица: номер превращается в play при наведении, у играющего трека — красный эквалайзер · клик по играющей строке ставит паузу · нижний плеер всегда виден: транспорт по центру, белая кнопка play, громкость справа.

Обложки рисуются на canvas и реагируют на музыку (те же три сюжета: солнце / световая штора / столбцы).
