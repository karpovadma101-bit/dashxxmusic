# «Город звучит» — версия 7: синтез v4 + v5 + v6

Финальный кандидат: собраны самые юзер-френдли решения трёх версий в одном целостном интерфейсе на дизайн-токенах А101 (белый фон, красный #E2232E, Onest, радиусы 20px).

## Что взято и откуда

| Из версии | Решение | Почему это самое юзер-френдли |
|---|---|---|
| v6 (Яндекс) | Светлая тема как на a101.ru | Единственная тема, совпадающая с брендом сайта; лучший контраст |
| v6 | «Волна» — один очевидный play в шаре | Одна главная кнопка на первом экране, нулевой порог входа |
| v6 | Чипы настроений | Выбор жанра словами («Город мечты»), а не терминами |
| v6 | Волна не останавливается | Треки идут подряд — слушатель ничего не должен делать |
| v5 (Spotify) | Постоянный нижний плеер | Управление всегда под рукой на любом экране, без скролл-триггеров |
| v5 | Клик по играющему треку = пауза | Привычный жест, строки-кнопки с hover-play |
| v4 (Apple Music) | Текст джингла рядом со списком треков | На десктопе всё видно сразу, без вкладок (sticky-карточка) |
| v4 | Горячие клавиши + диалог «Клавиши» | Пробел, стрелки, N/P, 1-2-3, M, ? |
| v4 | Громкость с mute и памятью (localStorage) | Настройка переживает перезагрузку |
| v4 | Подсказка времени на скраббере, спиннер загрузки | Обратная связь при каждом действии |
| v4 | Media Session API | Медиаклавиши клавиатуры и виджет ОС работают |

## Мобильная версия

Отдельно оптимизирована под телефон:

- **Первый экран 390×844 собирает всё**: волна, заголовок, три чипа, первый трек и плеер — без прокрутки.
- **Перемотка на телефоне**: красная нить по верхней кромке нижнего плеера, зона касания 26px, тап и драг. На десктопе вместо неё полноценный скраббер с подсказкой времени.
- **Тач-цели**: prev/next 44×44, play 50×50; в мобильном баре остаются только нужные кнопки (shuffle/repeat скрыты), под названием трека — текущее время.
- **Тач-логика**: тултипы и кнопка «Клавиши» скрыты там, где нет hover и клавиатуры; отступ под жестовую полосу iPhone (safe-area).

## Публикация

```bash
cp -R site-v7/* /путь/к/репозиторию/dashxxmusic/ && cd /путь/к/репозиторию/dashxxmusic && git add -A && git commit -m "Лендинг: финальная версия" && git push
```

Караоке-подсветка текста готова, но выключена (нет таймкодов): открыть с `?tune=1`, жать «Т» в начале строк, массив из консоли вписать в `cues`.
