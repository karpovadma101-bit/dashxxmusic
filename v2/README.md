# «Город звучит» — версия 2: плеер с эквалайзером

Первый экран — плеер, эквалайзер и переключатель жанров. Изображений на главном экране нет.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия для GitHub Pages (внешние ассеты) |
| `index-standalone.html` | Весь лендинг одним файлом, 2,7 МБ — открывается с диска, отправляется в мессенджере |
| `audio/` | Джинглы XXSOUND, AAC 128 kbps: 0:45 / 0:53 / 0:36 |
| `font/` | Onest (SIL OFL), кириллица + латиница, вариативный |

## Как устроен эквалайзер

- **До нажатия play** столбики показывают реальную форму волны выбранного трека — файл раскодируется через `decodeAudioData`, берутся пики. Подпись: «Форма трека».
- **После play** — живой спектр с `AnalyserNode` (FFT 512), с маркерами пиков, которые плавно оседают. Подпись меняется на «Спектр», индикатор — на «Играет».
- Таймлайн — тоже форма волны трека: прослушанная часть красная, остаток серый. Кликабельный, перемотка мышью и стрелками.
- Если `AudioContext` недоступен, эквалайзер рисует запасной профиль, звук при этом играет.

## Управление

`Space` — play/pause · стрелки на таймлайне — ±3 с · кнопки ⏮ ⏭ и три вкладки жанров · после трека автоматически включается следующий · мини-плеер появляется при прокрутке.

