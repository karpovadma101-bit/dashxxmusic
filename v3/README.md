# «Город звучит» — версия 3: Now Playing

Первый экран — полноэкранный плеер в логике Apple Music, собранный в айдентике А101: живая обложка, панель с текстом и очередью, фон подсвечивается цветом обложки.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия для GitHub Pages |
| `index-standalone.html` | Весь лендинг одним файлом, 2,8 МБ |
| `audio/` | Джинглы XXSOUND, AAC 128 kbps: 0:45 / 0:53 / 0:36 |
| `font/` | Onest (SIL OFL), кириллица + латиница |

## Живые обложки

Обложек как файлов нет — они рисуются на canvas и реагируют на музыку:

- **Pop** «Город мечты» — солнце над красным полем, кольца звука расходятся в такт басу.
- **Jazz** «Город с характером» — кобальтовая световая штора: визуальный код презентации XXSOUND.
- **Hip-hop** «Город в движении» — жёсткие красно-белые столбцы, высота берётся из спектра, диагональный росчерк.

Фон страницы — та же обложка, увеличенная и размытая, поэтому при смене трека меняется свет всей страницы. На паузе обложка продолжает еле заметно дышать.

## Построчная подсветка текста

Механизм готов, таймкодов пока нет — в `TR.<жанр>.cues` стоит `null`, и текст показывается целиком.

Чтобы включить караоке-подсветку:

1. Открыть страницу с `?tune=1`
2. Включить трек и нажимать клавишу **Т** в момент начала каждой строки
3. Скопировать массив из консоли в `cues` нужного трека (`Backspace` отменяет последнюю метку)

После этого строки подсвечиваются по одной и панель сама прокручивается к активной.

## Управление

`Space` — play/pause · стрелки на скраббере — ±3 с · ⏮ в первые 3 секунды переключает трек, дальше перематывает в начало · перемешивание и повтор работают · громкость · вкладки «Текст» / «Очередь» · мини-плеер при прокрутке.

## Публикация

```bash
cp -R site-v3/* /путь/к/репозиторию/dashxxmusic/ && cd /путь/к/репозиторию/dashxxmusic && git add -A && git commit -m "Лендинг: Now Playing" && git push
```

Перед публикацией: сделать `og:image` (можно снять скриншот обложки), обернуть a101.ru в ссылку с UTM, поставить счётчики на play, смену трека и дослушивание.

Перемотка требует поддержки HTTP Range на хостинге — GitHub Pages её поддерживает.
