# «Город звучит» — версия 4: десктопный плеер

Развитие версии 3 под большой экран. База — Now Playing из Apple Music, отдельные решения взяты у Spotify, Яндекс Музыки и VK Музыки.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия для GitHub Pages |
| `index-standalone.html` | Весь лендинг одним файлом, 2,8 МБ |
| `audio/` | Джинглы XXSOUND: 0:45 / 0:53 / 0:36 |
| `font/` | Onest (SIL OFL) |

## Раскладка

| Ширина | Что показывается |
|---|---|
| от 1400px | Три колонки в полный размер: плеер · текст · очередь |
| 1000–1399px | Те же три колонки, компактнее: уже обложка и строки очереди |
| 940–999px | Две колонки, панель с вкладками «Текст» / «Дальше» |
| до 940px | Одна колонка, плеер сверху |

Вкладок на десктопе нет: текст и очередь видны одновременно начиная с 1000px — это и есть главное отличие от версии 3.

## Что откуда взято

**Apple Music (основа):** полноэкранный Now Playing, крупная обложка с тенью, которая подрастает при запуске; тонкий скраббер; панель текста рядом с плеером; сдержанная типографика.

**Spotify:** нижняя панель плеера, которая появляется при прокрутке — обложка, название, транспорт, прогресс, кнопка возврата к плееру. Панель очереди не всплывает сама: она либо закреплена на широком экране, либо открывается вкладкой.

**Яндекс Музыка:** уроки из разбора их редизайна — трек запускается **одним кликом**, у строки очереди **одно действие** вместо набора кнопок при наведении, текст песни всегда набран живым шрифтом и не мылится.

**VK Музыка:** компактная строка «обложка + название + исполнитель» в нижней панели.

## Удобство

- Горячие клавиши: `Пробел`, `←/→` (±5 с), `↑/↓` (громкость), `N/P`, `1/2/3`, `M`, `?`. Кнопка «Клавиши» в шапке открывает шпаргалку — работает и с русской раскладкой.
- Подсказки на всех иконках: появляются и при наведении, и при фокусе с клавиатуры.
- Скраббер: зона захвата 22px, при наведении утолщается, над курсором показывает время в этой точке.
- Громкость с кнопкой «без звука», значение запоминается между визитами.
- Медиаклавиши ОС и виджет «Сейчас играет» (Media Session API): обложка отрисовывается в canvas и отдаётся системе.
- Кнопка «Поделиться» копирует ссылку в буфер.
- Индикатор играющего трека в очереди: анимированные полоски, на паузе — снова хронометраж.
- Спиннер на кнопке play, пока трек буферизуется.
- Контраст вторичного текста поднят до уровня AA, у всех интерактивных элементов зона не меньше 44px.

## Построчная подсветка текста

Как и в версии 3: механизм готов, `cues` пустые. Открыть с `?tune=1`, включить трек, жать `Т` в начале каждой строки, скопировать массив из консоли в `TR.<жанр>.cues`.

## Публикация

```bash
cp -R site-v4/* /путь/к/репозиторию/dashxxmusic/ && cd /путь/к/репозиторию/dashxxmusic && git add -A && git commit -m "Лендинг: десктопный плеер" && git push
```

Перед публикацией: сделать `og:image`, обернуть a101.ru в ссылку с UTM, поставить счётчики. Перемотка требует поддержки HTTP Range — на GitHub Pages она есть.
