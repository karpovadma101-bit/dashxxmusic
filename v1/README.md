# «Город звучит» — А101 × DASHXX

Лендинг спецпроекта, 3 экрана, десктоп + мобайл.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Прод-версия (внешние ассеты). Заливать на GitHub Pages / любой хостинг. |
| `index-standalone.html` | Тот же лендинг одним файлом (шрифты, картинки и аудио внутри, 4,5 МБ). Для отправки в мессенджере/по почте без хостинга. |
| `img/` | Рендеры А101: `hero.jpg` (двор, Pop), `evening.jpg` (вечер, Jazz), `pump.jpg` (памп-трек, Hip-hop) |
| `audio/` | Джинглы XXSOUND, AAC 128 kbps, 0:36–0:53 |
| `font/` | Onest (SIL Open Font License), кириллица + латиница, вариативный |

## Публикация на GitHub Pages

Скопировать содержимое папки в корень репозитория `dashxxmusic` (заменив старый `index.html`) и запушить:

```bash
cp -R site/* /путь/к/репозиторию/dashxxmusic/ && cd /путь/к/репозиторию/dashxxmusic && git add -A && git commit -m "Редизайн лендинга" && git push
```

## Что настроить перед публикацией

1. **og:image** в `<head>` — сейчас относительный путь `img/hero.jpg`; для корректных превью в мессенджерах заменить на абсолютный URL.
2. **Ссылка a101.ru** в футере — сейчас просто текст, при необходимости обернуть в `<a>` с UTM.
3. **Аналитика** — счётчиков нет. Полезные события: `play`, смена жанра, дослушивание трека до конца.

## Технические заметки

- Визуализация: район режется на 48 вертикальных колонок, высота каждой берётся из спектра трека (Web Audio API, `AnalyserNode`). На паузе — медленная волна.
- Если `AudioContext` недоступен (старый браузер, жёсткие настройки приватности), визуализация автоматически переходит в режим волны, звук при этом играет.
- Уважается `prefers-reduced-motion`: анимация отключается, кадр рисуется статично.
- Клавиатура: `Space` — play/pause, стрелки на таймлайне — перемотка ±3 c, фокус виден.
- Треки играют по кругу: Pop → Jazz → Hip-hop.
